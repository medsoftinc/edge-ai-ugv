# Edge AI UGV

Edge AI tabanlı görsel takip ve otonom seyir yapan insansız kara aracı (İKA).

Robot, kamerada seçilen hedefi gerçek zamanlı tespit edip takip eder, derinlik sensörüyle mesafesini ölçer, ortamın haritasını çıkarır ve engellerden kaçarak hedefe gider. Tüm işlem robot üzerindeki Jetson'da çalışır.

## Teknolojiler
ROS 2 Lyrical · Gazebo · Python · C++ · OpenVINO · TensorRT · Nav2 · SLAM
